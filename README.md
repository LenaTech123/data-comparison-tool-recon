# Data Jämförelse Tool

En Streamlit-app som jämför Salesforce-data med Google Sheets-data och genererar Excel-rapporter.

## Funktioner
- Automatisk datamatchning mellan Salesforce och Google Sheets
- Namn-mappning för kända avvikelser
- Excel-rapportgenerering
- Oskarp textmatchning för flexibel matchning

## Installation
1. Klona projektet
2. Installera dependencies: `pip install -r requirements.txt`
3. Konfigurera secrets
4. Kör: `streamlit run app.py`
